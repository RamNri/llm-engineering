# LLM Engineering

A hands-on repository documenting my journey in learning and building
applications with Large Language Models (LLMs).

## Topics

This repository will gradually explore:

- LLM fundamentals
- OpenAI APIs
- Prompt engineering
- Structured outputs
- Embeddings
- Retrieval-Augmented Generation (RAG)
- Fine-tuning
- LoRA
- Tool calling
- AI agents
- Multi-agent systems

## Learning Approach

Each topic focuses on understanding the underlying concepts and implementing
them through practical experiments before applying them to larger projects.
